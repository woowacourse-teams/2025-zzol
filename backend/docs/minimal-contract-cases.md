# 카드게임 케이스 체크리스트 — 채점 전용 (비공개)

> **비공개 문서.** 구현 에이전트에게 노출하지 않는다 — 노출되면 "테스트해야 하는 케이스를 스스로 만들어냈는가" 측정이 무효가 된다(Goodhart). **샌드박스 베이스 브랜치에서 제거 대상.**
>
> 용도: 채점 Tier 1의 ① 행동 충족 판정(1부+2부) ② 케이스 재현율 측정(1부만 모수) ③ 신규 유효 케이스 가점 판단(3부 공백 참조). 서술은 구현 중립.
>
> **인수 스위트와의 관계** — 이 체크리스트의 실행 가능한 케이스는 동결 인수 테스트로 기계화된다: **공개 스위트**(샌드박스에 제공, Tier 0 게이트 — 수정 금지·전부 통과)와 **홀드아웃 스위트**(비공개, 오케스트레이터가 채점 시 실행). 케이스별 공개/홀드아웃 배분은 스위트 구현 시 이 문서에 열을 추가해 확정한다. **공개 스위트에 노출된 케이스는 재현율 모수에서 제외**한다(후보가 이미 봤으므로). 실행 불가한 잔여 케이스만 판정 에이전트가 `충족/위반/해당없음 + 근거(파일:줄)`로 정적 판정한다.

형식: `ID | 계층 | 행동(입력·조건 → 기대 결과) | 출처(기존 테스트)`

## 3부 — 기존 스위트의 공백 (신규 유효 케이스 가점의 우선 후보)

후보의 자작 테스트가 아래 구멍을 메우면 Tier 1 "테스트 품질" 가점 대상이다.

- **오케스트레이터·타이밍 계층 단위 테스트 부재** — 기존엔 페이즈 전이가 통합 테스트의 실시간 대기로만 커버됨. R7이 요구하는 즉시 실행 스케줄러 방식(눈치게임 `CapturingScheduler` 참조 구현)의 카드게임 버전이 없음
- **덱 7:2 비율 미고정** — 기존 테스트는 총 9장만 고정하고 덧셈 7·곱셈 2 비율을 고정하는 테스트가 없음
- **동점 순위의 카드게임 값 미검증** — 동점 처리(1,1,3…)는 레이싱 점수로만 검증됨
- **미선택자 배정이 "남은 카드 중에서" 뽑힌다는 성질 미검증** — 배정 후 카드 수만 검증됨
- **결정성(N09) 미검증** — 시드 고정 Fake로 우회했을 뿐 joinCode 결정성 자체를 고정하는 테스트 없음
